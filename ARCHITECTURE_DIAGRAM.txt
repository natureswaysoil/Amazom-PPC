║                            DATA FLOW DIAGRAM                                  ║
╚═══════════════════════════════════════════════════════════════════════════════╝

User Action (Date Filter)
    ↓
Frontend JavaScript (filters.js)
    ↓
API Request (api.js) → GET /api/dashboard/revenue?start_date=X&end_date=Y
    ↓
Backend API (dashboard_api.py)
    ↓
Check Cache (cache_manager.py)
    ├─ Cache Hit  → Return Cached Data → Frontend
    └─ Cache Miss → Continue ↓
                    ↓
    Authenticate (amazon_sp_api.py)
        ├─ Get Credentials from Secret Manager
        ├─ Refresh Token if Expired
        └─ Create Authenticated Session
                    ↓
    Call Amazon SP-API
        ├─ Orders API
        ├─ Inventory API
        └─ Catalog Items API
                    ↓
    Process & Transform Data
                    ↓
    Store in Cache (TTL: 5-10 min)
                    ↓
    Store in BigQuery (Historical)
                    ↓
    Return JSON Response
                    ↓
Frontend Updates (dashboard.js)
    ├─ Update KPI Cards
    ├─ Render Charts (charts.js)
    └─ Update Tables
